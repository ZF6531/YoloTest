## 一、网络架构

### 1.1 整体结构

YOLOv3 采用 **Darknet-53** 作为骨干网络，引入残差连接，并首次实现 **多尺度预测**。

```
输入图像 (416×416×3 或任意32倍数)
    ↓
┌─────────────────────────────────────────┐
│  Backbone: Darknet-53                   │
│  - 53个卷积层（含残差连接）              │
│  - 无全连接层、无池化层（用stride=2卷积） │
│  - 全卷积网络，支持任意输入尺寸          │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  多尺度预测（FPN思想）                   │
│  ┌──────────────────────────────────┐  │
│  │  13×13 特征图 → 检测大目标        │  │  ← 52层后，尺度1（最大感受野）
│  │  (255通道 = 3×(5+80))             │  │
│  └──────────┬───────────────────────┘  │
│             │ 上采样 + 拼接              │
│  ┌──────────┴───────────────────┐      │
│  │  26×26 特征图 → 检测中目标    │      │  ← 26层后，尺度2
│  │  (255通道 = 3×(5+80))         │      │
│  └──────────┬───────────────────┘      │
│             │ 上采样 + 拼接              │
│  ┌──────────┴───────────┐              │
│  │  52×52 特征图 → 检测小目标│          │  ← 最浅层，尺度3（最小感受野）
│  │  (255通道 = 3×(5+80))     │          │
│  └──────────────────────────┘          │
└─────────────────────────────────────────┘
```

### 1.2 Darknet-53 骨干网络

```
输入: 256×256×3

┌────────────────────────────────────────────────────────────────┐
│ Conv(3×3, 32)                                                  │
│ Conv(3×3, 64, /2)      → 128×128                               │
│ ┌──────────────────────────────────────────────────────────┐  │
│ │ Residual Block ×1: Conv(1×1,32) → Conv(3×3,64)           │  │
│ └──────────────────────────────────────────────────────────┘  │
│ Conv(3×3, 128, /2)     → 64×64                                │
│ ┌──────────────────────────────────────────────────────────┐  │
│ │ Residual Block ×2                                        │  │
│ └──────────────────────────────────────────────────────────┘  │
│ Conv(3×3, 256, /2)     → 32×32                                │
│ ┌──────────────────────────────────────────────────────────┐  │
│ │ Residual Block ×8  ───────────────────────────────────┐  │  │
│ │ （YOLOv3在这里第一次输出，用于检测小目标）              │  │  │
│ └──────────────────────────────────────────────────────────┘  │
│ Conv(3×3, 512, /2)     → 16×16                                │
│ ┌──────────────────────────────────────────────────────────┐  │
│ │ Residual Block ×8  ───────────────────────────────────┐  │  │
│ │ （YOLOv3在这里第二次输出，用于检测中目标）              │  │  │
│ └──────────────────────────────────────────────────────────┘  │
│ Conv(3×3, 1024, /2)    → 8×8                                  │
│ ┌──────────────────────────────────────────────────────────┐  │
│ │ Residual Block ×4  ───────────────────────────────────┐  │  │
│ │ （YOLOv3在这里第三次输出，用于检测大目标）              │  │  │
│ └──────────────────────────────────────────────────────────┘  │
│ AvgPool + FC + Softmax (分类预训练时使用)                       │
└────────────────────────────────────────────────────────────────┘
```

### 1.3 残差块（Residual Block）

```
输入 x
    │
    ├──→ [Conv 1×1] → [Conv 3×3] → 输出 ──→ ⊕ ──→ 最终输出
    │                                          ↑
    └──────────────────────────────────────────┘
                 跳跃连接（Skip Connection）

作用：
- 缓解梯度消失，训练更深的网络
- 允许网络学习残差（变化量），而非直接学习映射
```

### 1.4 多尺度预测详解

```
特征金字塔网络（FPN）风格的特征融合：

深层特征（语义强）              浅层特征（定位准）
┌───────────┐                  ┌───────────┐
│  8×8×1024 │ 检测大目标        │ 64×64×256 │
│  感受野大  │  需要语义        │  感受野小  │ 检测小目标
│  语义丰富  │                  │  定位精确  │
└─────┬─────┘                  └───────────┘
      │
      ↓ 卷积预测 (13×13×255)
      │
      ↓ 上采样 2× + 拼接 26×26×512
      │
┌─────┴─────┐
│ 26×26×768 │ 检测中目标
└─────┬─────┘
      │
      ↓ 卷积预测 (26×26×255)
      │
      ↓ 上采样 2× + 拼接 52×52×256
      │
┌─────┴─────┐
│ 52×52×384 │ 检测小目标
└───────────┘
      │
      ↓ 卷积预测 (52×52×255)
```

### 1.5 输出张量解析

每个尺度输出张量：S×S×255（COCO 数据集，80类）

```
255 = 3 × (5 + 80)
      │    │   └── 类别概率
      │    └────── 边界框参数 (tx, ty, tw, th, obj)
      └─────────── 每个尺度3个anchor

三个尺度的Anchor分配：
┌──────────────────────────────────────────────────────────────┐
│  尺度1 (13×13): 大anchor  - (116,90), (156,198), (373,326)   │
│  尺度2 (26×26): 中anchor  - (30,61), (62,45), (59,119)      │
│  尺度3 (52×52): 小anchor  - (10,13), (16,30), (33,23)       │
└──────────────────────────────────────────────────────────────┘

总预测框数：13×13×3 + 26×26×3 + 52×52×3 = 10647 个框
```

## 二、关键改进

### 2.1 相比 YOLOv2 的核心改进

| 改进点 | YOLOv2 | YOLOv3 | 效果 |
|:---:|:---:|:---:|:---|
| **骨干网络** | Darknet-19 | Darknet-53 | 特征提取更强 |
| **残差连接** | 无 | 全网络 | 训练更深网络 |
| **多尺度预测** | 单层13×13 | 三层(13/26/52) | 小目标检测↑ |
| **特征融合** | Passthrough | FPN式上采样拼接 | 语义+定位结合 |
| **分类器** | Softmax | 独立Logistic | 多标签支持 |
| **Anchor** | 5个 | 9个（每尺度3个）| 更精细匹配 |

### 2.2 分类器改进：独立 Logistic

**YOLOv2/v1 的问题：**
- 使用 Softmax，假设类别互斥
- 无法处理 "人" 和 "女人" 同时存在的问题

**YOLOv3 的解决：**

```python
# YOLOv2: Softmax（类别互斥）
probs = softmax(outputs)  # 所有类和为1

# YOLOv3: 独立 Logistic（类别独立）
probs = sigmoid(outputs)  # 每个类0-1独立

# 可以同时是人、女人、运动员等多个标签
```

**适用场景：**
- 多标签分类（Open Images 数据集）
- 类别有重叠（如 "人" 包含 "女人"）

### 2.3 边界框预测改进

```
每个 anchor 负责一个 ground truth：

1. 计算 ground truth 与所有 anchor 的 IOU
2. 选择 IOU 最大的 anchor 负责预测
3. 如果 anchor 与 ground truth IOU > 0.5 但不是最大：忽略（不参与损失）
4. 如果 anchor 与所有 ground truth IOU < 0.5：负样本

损失函数简化：
- 只计算正样本的坐标损失和分类损失
- 负样本只计算置信度损失
```

## 四、面试要点

### 4.1 高频问题

**Q1: YOLOv3 相比 YOLOv2 的主要改进是什么？**

```
答：
1. 骨干网络升级为 Darknet-53，引入残差连接
2. 多尺度预测：在 13×13、26×26、52×52 三个尺度预测
3. 特征金字塔网络（FPN）风格：深层特征上采样与浅层融合
4. 分类器改为独立 Logistic，支持多标签分类
5. Anchor 增加到 9 个，每尺度分配 3 个
6. 小目标检测能力大幅提升
```

**Q2: YOLOv3 为什么使用多尺度预测？**

```
答：
问题：单层 13×13 对小目标检测不好

解决：
- 52×52 尺度：感受野小，特征图大，适合检测小目标
- 26×26 尺度：中等感受野，检测中等目标
- 13×13 尺度：感受野大，语义丰富，检测大目标

特征融合方式：
- 深层特征（语义强）上采样 2 倍
- 与浅层特征（定位准）按通道拼接
- 每个融合后的特征图进行预测
```

**Q3: Darknet-53 中的残差连接有什么作用？**

```
答：
1. 缓解梯度消失：跳跃连接让梯度直接回传
2. 训练更深网络：Darknet-53 比 Darknet-19 深但训练更容易
3. 学习残差映射：网络学习 F(x) = H(x) - x，而非直接学习 H(x)
4. 恒等映射：如果某层不需要，可以通过残差学习为 0

残差块结构：
输入 x → [Conv 1×1] → [Conv 3×3] → 输出 + x → ReLU
```

**Q4: YOLOv3 为什么要用 Logistic 代替 Softmax？**

```
答：
Softmax 假设类别互斥：
- 人、狗、猫 - 适合（一张图不可能同时是狗和猫）
- 人、女人、运动员 - 不适合（可以同时成立）

Logistic（Sigmoid）每个类别独立：
- 输出 0-1 的概率
- 可以同时有多个类别概率高
- 适合 Open Images 等多标签数据集
```

**Q5: YOLOv3 的 anchor 分配策略是什么？**

```
答：
1. 9 个 anchor 通过 K-means 在 COCO 上聚类得到
2. 按大小分配到三个尺度：
   - 大 anchor（116×90等）→ 13×13 检测大目标
   - 中 anchor（30×61等）→ 26×26 检测中目标
   - 小 anchor（10×13等）→ 52×52 检测小目标
3. 每个 ground truth 只分配给 IOU 最大的 anchor
4. 其他 IOU>0.5 的 anchor：不参与损失（忽略）
5. IOU<0.5 的 anchor：负样本，只计算置信度损失
```

### 4.2 手撕代码要点

```python
# YOLOv3 多尺度预测示意图
def yolov3_forward(x):
    """
    简化版 YOLOv3 前向传播
    """
    # Backbone: Darknet-53
    c1, c2, c3 = darknet53(x)  # c1:52×52, c2:26×26, c3:13×13
    
    # 尺度1：检测大目标（13×13）
    p1 = conv_block(c3)
    out1 = predict(p1)  # 13×13×255
    
    # 上采样与 c2 融合，检测中等目标（26×26）
    up1 = upsample(p1, scale_factor=2)
    f2 = torch.cat([up1, c2], dim=1)  # 通道拼接
    p2 = conv_block(f2)
    out2 = predict(p2)  # 26×26×255
    
    # 上采样与 c1 融合，检测小目标（52×52）
    up2 = upsample(p2, scale_factor=2)
    f3 = torch.cat([up2, c1], dim=1)
    p3 = conv_block(f3)
    out3 = predict(p3)  # 52×52×255
    
    return out1, out2, out3  # 三个尺度的预测

# 多标签分类（独立 Logistic）
def multilabel_classification(logits):
    """
    YOLOv3 使用 sigmoid 代替 softmax
    """
    probs = torch.sigmoid(logits)  # 每个类别独立 0-1
    # 阈值判断，可以有多个类别
    predictions = (probs > 0.5).float()
    return predictions
```

## 五、总结

| 特性 | YOLOv3 改进 |
|:---:|:---|
| **骨干网络** | Darknet-53 + 残差连接，更强的特征提取 |
| **多尺度** | 三个尺度预测，小目标检测质的飞跃 |
| **特征融合** | FPN 式上采样拼接，语义+定位结合 |
| **多标签** | 独立 Logistic 分类器，支持重叠类别 |
| **速度精度** | 320 输入 45FPS/51.5mAP，608 输入 20FPS/57.9mAP |

**一句话：** YOLOv3 通过多尺度预测、残差网络和特征金字塔，在保持实时性的同时大幅提升小目标检测能力，成为工业界最常用的检测器之一。
