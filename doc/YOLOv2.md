## 一、网络架构

### 1.1 整体结构

YOLOv2 采用全新的 **Darknet-19** 作为骨干网络，相比 YOLOv1 的 24 层卷积，更加轻量高效。

```
输入图像 (416×416×3)  # 输入尺寸改为416，可被32整除
    ↓
┌─────────────────────────────────────────┐
│  Backbone: Darknet-19                   │
│  - 19个卷积层                            │
│  - 5个Max Pooling                        │
│  - 全局平均池化替代全连接层               │
│  - 最终特征图: 13×13×1024                │
│  - Batch Normalization 贯穿全程          │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  Head: 去掉全连接层，使用卷积预测         │
│  - 1×1卷积调整通道数                     │
│  - 输出: 13×13×(B×(5+C))                 │
│  - B=5个Anchor Boxes                     │
└─────────────────────────────────────────┘
    ↓
输出: 13×13 网格，每个网格预测 5 个 bounding boxes
```

### 1.2 Darknet-19 详细结构

| 类型 | 滤波器 | 尺寸 | 输出尺寸 |
|:---:|:---:|:---:|:---:|
| Conv | 32 | 3×3 | 416×416×32 |
| MaxPool | - | 2×2/2 | 208×208×32 |
| Conv | 64 | 3×3 | 208×208×64 |
| MaxPool | - | 2×2/2 | 104×104×64 |
| Conv | 128 | 3×3 | 104×104×128 |
| Conv | 64 | 1×1 | 104×104×64 |
| Conv | 128 | 3×3 | 104×104×128 |
| MaxPool | - | 2×2/2 | 52×52×128 |
| Conv | 256 | 3×3 | 52×52×256 |
| Conv | 128 | 1×1 | 52×52×128 |
| Conv | 256 | 3×3 | 52×52×256 |
| MaxPool | - | 2×2/2 | 26×26×256 |
| Conv | 512 | 3×3 | 26×26×512 |
| Conv | 256 | 1×1 | 26×26×256 |
| Conv | 512 | 3×3 | 26×26×512 |
| Conv | 256 | 1×1 | 26×26×256 |
| Conv | 512 | 3×3 | 26×26×512 |
| MaxPool | - | 2×2/2 | 13×13×512 |
| Conv | 1024 | 3×3 | 13×13×1024 |
| Conv | 512 | 1×1 | 13×13×512 |
| Conv | 1024 | 3×3 | 13×13×1024 |
| Conv | 512 | 1×1 | 13×13×512 |
| Conv | 1024 | 3×3 | 13×13×1024 |
| Conv | 1024 | 3×3 | 13×13×1024 |
| Conv | 1024 | 3×3 | 13×13×1024 |
| Conv | 125 | 1×1 | 13×13×125 |

> 125 = 5 × (5 + 20)，其中 5 是 anchor 数，20 是 VOC 类别数

### 1.3 输出张量解析

最终输出为 **13×13×125** 的张量（VOC数据集）：

- **13×13**: 网格划分，相比 YOLOv1 的 7×7 更精细
- **125 = 5 × 25**: 每个 grid cell 预测 5 个 anchor boxes
- **25 = 5 + 20**: 每个 box 包含 5 个回归参数 + 20 个类别概率

```
每个 Anchor Box 的 25 维向量:
┌──────────────────────────────────────────────────────────────┐
│  [tx, ty, tw, th, to]  +  [p1, p2, ..., p20]                 │
│  (5维边界框参数)          (20维类别概率)                       │
│                                                              │
│  tx, ty: 相对于 anchor 的偏移（sigmoid归一化到0-1）            │
│  tw, th: 相对于 anchor 宽高的 log 缩放                        │
│  to: objectness 置信度                                        │
└──────────────────────────────────────────────────────────────┘
```

## 二、关键改进

### 2.1 相比 YOLOv1 的核心改进

| 改进点 | YOLOv1 | YOLOv2 | 效果 |
|:---:|:---:|:---:|:---|
| **Batch Normalization** | 无 | 所有卷积层后 | mAP +2% |
| **高分辨率分类器** | 224×224 | 448×448 | mAP +4% |
| **Anchor Boxes** | 直接预测 | K-means聚类先验 | 召回率↑ |
| **维度聚类** | 无 | K-means选anchor | 更好拟合 |
| **细粒度特征** | 无 | Passthrough层 | 小目标↑ |
| **多尺度训练** | 固定448 | 每10batch换尺寸 | 鲁棒性↑ |

### 2.2 Batch Normalization

```python
# 在每一层卷积后加入 BN
Conv → BN → Leaky ReLU
```

**作用：**
- 加速收敛，允许更大学习率
- 正则化效果，降低过拟合
- 可以去除 Dropout

**效果：mAP 提升 2%**

### 2.3 高分辨率分类器

```
训练阶段：
┌─────────────────────────────────────────────────────────────┐
│  ImageNet 预训练：                                          │
│    1. 先用 224×224 训练 160 epochs（传统）                   │
│    2. 再用 448×448 训练 10 epochs（适应高分辨率）            │
│                                                             │
│  微调检测：448×448 输入                                      │
└─────────────────────────────────────────────────────────────┘
```

**效果：mAP 提升 4%**

### 2.4 Anchor Boxes 与维度聚类

**YOLOv1 的问题：**
- 直接预测 w, h，范围大，不稳定
- 每个 grid cell 只能预测 2 个框，召回率低

**YOLOv2 的解决：**

```
K-means 聚类获取 Anchor Boxes：

数据集所有 ground truth 框 ──→ K-means 聚类 ──→ 5个 Anchor
        ↓                                         ↓
   (w, h) 集合                              代表常见形状
   
距离度量：d(box, centroid) = 1 - IOU(box, centroid)
（不用欧氏距离，避免大框小框权重不均）

COCO 数据集上聚类结果示例：
- (0.57273, 0.677385)   # 竖长形
- (1.87446, 2.06253)    # 大框
- (3.33843, 5.47434)    # 超大框
- (7.88282, 3.52778)    # 横宽形
- (9.77052, 9.16828)    # 全图
```

**预测方式（相对 Anchor）：**

```python
# 网络预测的是相对于 anchor 的偏移
tx, ty, tw, th, to = network_output

bx = sigmoid(tx) + cx          # 相对于 grid cell 的中心 x
by = sigmoid(ty) + cy          # 相对于 grid cell 的中心 y
bw = pw * exp(tw)              # anchor 宽 × 指数缩放
bh = ph * exp(th)              # anchor 高 × 指数缩放
objectness = sigmoid(to)       # 置信度
```

### 2.5 Passthrough 层（细粒度特征）

**问题：** 13×13 的特征图对小目标检测不够好

**解决：** 将 26×26×512 的特征图"拆分"拼接到 13×13

```
26×26×512 ──→ 13×13×2048 ──→ 与 13×13×1024 拼接 ──→ 13×13×3072
     ↓
  隔点采样，
  把相邻4个点放到通道维度
  
直观理解：
┌───┬───┐
│ A │ B │      ┌───────┐
├───┼───┤  →   │A,B,C,D│  按通道堆叠
│ C │ D │      └───────┘
└───┴───┘
```

**效果：mAP 提升 1%**

### 2.6 多尺度训练

```
每 10 个 batch 随机更换输入尺寸：

Batch 1-10:   320×320
Batch 11-20:  416×416
Batch 21-30:  480×480
Batch 31-40:  608×608
Batch 41-50:  352×352
...

尺寸必须是 32 的倍数（因为下采样了 5 次，2^5=32）
```

**效果：** 网络学会对不同尺度输入鲁棒，速度和精度可权衡

## 三、YOLO9000：检测9000类物体

### 3.1 联合训练策略

```
目标：用检测数据（COCO）+ 分类数据（ImageNet）联合训练

问题：检测数据集有 bounding box 但类别少
      分类数据集类别多（ImageNet 22000类）但没有框

解决：WordTree 层次分类
```

### 3.2 WordTree 层次结构

```
物理对象
├── 动物
│   ├── 脊椎动物
│   │   ├── 哺乳动物
│   │   │   ├── 狗
│   │   │   │   ├── 金毛
│   │   │   │   └── 哈士奇
│   │   │   └── 猫
│   │   └── 鸟类
│   └── 无脊椎动物
├── 交通工具
│   ├── 陆地
│   │   └── 汽车
│   └── 水上
└── ...

从 ImageNet 9000+ 类构建 WordTree
```

### 3.3 条件概率预测

```
使用 Softmax 的层次版本：

Pr(金毛 | 物理对象) = Pr(金毛 | 狗) × Pr(狗 | 哺乳动物) × ...

训练时：
- 检测样本：更新检测损失 + 分类损失
- 分类样本：只更新分类损失（反向传播到共享层）
```

## 五、面试要点

### 5.1 高频问题

**Q1: YOLOv2 相比 YOLOv1 有哪些主要改进？**

```
答：
1. Batch Normalization：所有卷积层后加入BN，提升2% mAP
2. 高分辨率分类器：预训练使用448×448，适应检测高分辨率
3. Anchor Boxes：用K-means聚类获得先验框，直接预测偏移
4. 去掉全连接层：全卷积网络，支持多尺度输入
5. Passthrough层：融合26×26细粒度特征，提升小目标检测
6. 多尺度训练：每10batch随机换尺寸，增强鲁棒性
7. 新骨干网络：Darknet-19，比VGG更快
```

**Q2: 为什么要用 K-means 聚类 Anchor Boxes？**

```
答：
1. 手工设计anchor（如Faster R-CNN的9种）可能不适合特定数据集
2. K-means根据数据集真实框的分布自动学习最优形状
3. 距离度量用1-IOU，确保anchor形状与真实框匹配度高
4. K=5是速度和精度的平衡点（作者实验K=5 vs K=9）
```

**Q3: YOLOv2 的边界框预测公式是什么？与 YOLOv1 有什么不同？**

```
答：
YOLOv1：直接预测归一化的(x, y, w, h)
YOLOv2：预测相对于anchor的偏移

bx = sigmoid(tx) + cx    # cx是grid cell左上角坐标
by = sigmoid(ty) + cy
bw = pw * exp(tw)        # pw是anchor的宽
bh = ph * exp(th)

优点：
1. 使用anchor先验，预测更稳定
2. 使用log-space预测尺寸变化，避免极端值
3. sigmoid限制中心偏移在0-1，保证落在grid内
```

**Q4: Passthrough 层是怎么工作的？**

```
答：
- 将26×26×512的特征图变成13×13×2048
- 方法：把26×26的空间维度"折叠"到通道维度
- 具体：相邻2×2区域的特征按通道堆叠
- 然后与13×13×1024的主特征图拼接，得到13×13×3072
- 作用：保留细粒度空间信息，帮助检测小目标
```

**Q5: YOLO9000 是如何实现检测9000类的？**

```
答：
1. 使用WordTree构建类别层次结构
2. 联合训练：COCO检测数据 + ImageNet分类数据
3. 检测样本：更新检测损失和分类损失
4. 分类样本：只反向传播分类损失到共享层
5. 预测时使用条件概率：Pr(子类|父类) × Pr(父类)
6. 即使某个类别没有检测标注，也能通过分类数据学习
```

### 5.2 手撕代码要点

```python
# YOLOv2 边界框预测（相对于anchor）
def predict_bbox(tx, ty, tw, th, to, cx, cy, pw, ph):
    """
    tx, ty, tw, th, to: 网络输出
    cx, cy: grid cell 的左上角坐标（整数）
    pw, ph: anchor 的宽高
    """
    bx = torch.sigmoid(tx) + cx      # 中心x（相对于全图）
    by = torch.sigmoid(ty) + cy      # 中心y（相对于全图）
    bw = pw * torch.exp(tw)          # 宽
    bh = ph * torch.exp(th)          # 高
    conf = torch.sigmoid(to)         # 置信度
    
    return bx, by, bw, bh, conf

# K-means 聚类获取 anchor（简化版）
def kmeans_anchors(boxes, k=5):
    """
    boxes: [[w, h], ...] 所有ground truth框
    """
    # 随机初始化k个质心
    centroids = random.sample(boxes, k)
    
    while not converged:
        # 分配每个框到最近的质心
        clusters = [[] for _ in range(k)]
        for box in boxes:
            d = [1 - iou(box, c) for c in centroids]
            clusters[argmin(d)].append(box)
        
        # 更新质心
        for i in range(k):
            centroids[i] = mean(clusters[i])
    
    return centroids
```

## 六、总结

| 特性 | YOLOv2 改进 |
|:---:|:---|
| **速度** | 67 FPS，Darknet-19 比 VGG 更快 |
| **精度** | 76.8% mAP，超越 Faster R-CNN |
| **Anchor** | K-means 聚类 + 预测偏移，召回率大幅提升 |
| **小目标** | Passthrough 层融合高分辨率特征 |
| **多尺度** | 每10batch随机换尺寸，支持320-608灵活输入 |
| **扩展性** | YOLO9000 实现9000类联合训练 |

**一句话：** YOLOv2 通过引入 Anchor Boxes、Batch Norm、多尺度训练等改进，在速度和精度上都超越了同时期的两阶段检测器。
