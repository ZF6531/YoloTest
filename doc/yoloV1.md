## 一、网络架构

### 1.1 整体结构

YOLOv1 将目标检测视为**单一的回归问题**，直接从图像像素到边界框坐标和类别概率的映射。

```
输入图像 (448×448×3)
    ↓
┌─────────────────────────────────────────┐
│  Backbone: 24层卷积网络 (ImageNet预训练)  │
│  - 主要使用 3×3 卷积提取特征              │
│  - 使用 1×1 卷积降维                      │
│  - 2×2 Max Pooling 下采样 (stride=2)      │
│  - 最终特征图: 7×7×1024                   │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│  Head: 2层全连接层                       │
│  - FC1: 4096 神经元 (Dropout 0.5)         │
│  - FC2: 7×7×30 = 1470 输出                │
└─────────────────────────────────────────┘
    ↓
输出: 7×7 网格，每个网格预测 2 个 bounding boxes
```

### 1.3 输出张量解析

最终输出为 **7×7×30** 的张量：

- **7×7**: 图像被划分为 7×7 的网格 (grid cells)
- **30**: 每个 grid cell 预测 2 个 bounding box，每个 box 包含 5 个值 + 20 个类别概率

```
每个 grid cell 的 30 维向量:
┌──────────────────────────────────────────────────────────────┐
│  Box 1: [x, y, w, h, confidence]  +  Box 2: [x, y, w, h, confidence] + 20 classes │
│  (5维)                              (5维)                              (20维)      │
└──────────────────────────────────────────────────────────────┘
                      5 + 5 + 20 = 30
```

其中：
- **(x, y)**: bounding box 中心相对于 grid cell 的偏移 (0-1)
- **(w, h)**: bounding box 宽高相对于整幅图像的比例 (0-1)
- **confidence**: 置信度 = Pr(Object) × IOU(pred, truth)
- **20 classes**: 条件类别概率 Pr(Class_i | Object)，使用 PASCAL VOC 数据集

## 二、设计原理

### 2.1 统一检测框架 (Unified Detection)

**传统方法 (Two-stage):**
```
图像 → 提取候选框 (Selective Search/RPN) → 特征提取 → 分类 + 回归
         (R-CNN系列)        (CNN)         (SVM/FC)
```
问题：分阶段处理，速度慢，各阶段独立优化

**YOLO 方法 (One-stage):**
```
图像 → 单次 CNN 前向传播 → 直接输出所有目标的类别和位置
```
优势：端到端训练，全局优化，实时性强

### 2.2 网格预测机制

1. **Grid Cell 负责机制**: 每个 grid cell 负责预测中心点落在该 cell 内的目标
2. **多框预测**: 每个 cell 预测 2 个 bounding boxes，但只负责一个类别（取 IOU 最高的框）
3. **全卷积思想**: 整个网络可视为一个全卷积网络，具有平移不变性

### 2.3 损失函数设计

YOLOv1 使用**多任务损失函数**，包含三个部分：

```python
# 总损失 = 坐标损失 + 置信度损失 + 分类损失
L = λ_coord × L_coord + L_conf + L_cls
```

**1. 坐标损失 (Coordinate Loss)**

```
L_coord = Σ[obj] [ (x - x̂)² + (y - ŷ)² ]          # 中心点位置损失
        + Σ[obj] [ (√w - √ŵ)² + (√h - √ĥ)² ]      # 宽高损失（开根号处理小框）
```

> 使用平方根的原因：大框和小框的绝对误差相同但相对精度不同，开根号可以缓和这种差异

**2. 置信度损失 (Confidence Loss)**

```
L_conf = Σ[obj] (C - Ĉ)²                    # 有目标的 cell
       + λ_noobj × Σ[noobj] (C - Ĉ)²        # 无目标的 cell（权重降低）
```

> λ_noobj = 0.5: 解决正负样本不平衡问题（大部分 grid cells 不含目标）

**3. 分类损失 (Classification Loss)**

```
L_cls = Σ[obj] Σ[c∈classes] (p(c) - p̂(c))²   # 条件类别概率的 MSE
```

**损失权重设置：**
- λ_coord = 5（增强定位精度的重要性）
- λ_noobj = 0.5（降低背景置信度损失的权重）

### 2.4 训练策略

**预训练阶段：**
- 使用 ImageNet 数据集预训练前 20 层卷积网络
- 输入尺寸：224×224
- 分类任务训练，获得良好的特征提取能力

**检测微调阶段：**
- 添加 4 层卷积 + 2 层全连接
- 输入尺寸提升到 448×448（更高分辨率有助于检测）
- 在 PASCAL VOC 2007+2012 上训练约 135 epochs
- 学习率：前 75 epochs: 10⁻³，后 30 epochs: 10⁻⁴，最后 30 epochs: 10⁻⁵

## 三、设计亮点

### 3.1 核心创新

| 亮点 | 说明 | 影响 |
|:---:|:---|:---|
| **端到端检测** | 将检测转化为回归问题，单网络前向传播完成检测和分类 | 速度极快 (45 FPS)，实现实时检测 |
| **全局推理** | 整个图像作为上下文，同时预测所有边界框 | 减少背景误检，学习目标间关系 |
| **网格预测** | 7×7 网格 + 每格 2 框的预测机制 | 简化输出结构，便于训练 |
| **联合损失** | 多任务损失的权重设计 | 平衡定位与分类任务 |

### 3.2 速度优势

```
方法          FPS      mAP (VOC 2007)
─────────────────────────────────────
Fast YOLO     155      52.7%
YOLO          45       63.4%
Fast R-CNN    0.5      70.0%
Faster R-CNN  7        73.2%
```

> YOLO 的速度是 Faster R-CNN 的 6 倍以上，同时 mAP 差距在可接受范围

### 3.3 泛化能力

- 在自然图像上训练，在艺术画作上测试时，YOLO 的泛化性能显著优于 DPM 和 R-CNN
- 原因：YOLO 学习的是目标的通用表征，而非特定数据集的特征

## 四、局限性与改进方向

### 4.1 YOLOv1 的局限

1. **定位精度低**
   - 每个 grid cell 只能预测 2 个框且只有 1 个类别
   - 对小目标和密集目标检测效果差
   - 只能学习特定尺度的特征（没有多尺度预测）

2. **定位误差来源**
   - 使用粗粒度的 7×7 网格
   - 直接预测坐标而非偏移量
   - 损失函数使用 MSE，对大框小框惩罚相同

3. **召回率较低**
   - 相比 two-stage 方法，漏检率较高
   - 对于重叠目标、小目标不友好

### 4.2 后续改进

| 版本 | 主要改进 |
|:---:|:---|
| YOLOv2 | BatchNorm, 高分辨率分类器, Anchor Boxes, 多尺度训练 |
| YOLOv3 | DarkNet-53, 多尺度预测 (3个尺度), 独立逻辑回归分类器 |
| YOLOv4 | CSPDarknet53, SPP, PANet, Mosaic增强, 多种tricks |
| YOLOv5 | PyTorch实现, AutoAnchor, Focus切片, 更好的工程实现 |

## 五、面试要点总结

### 5.1 高频问题

**Q1: YOLOv1 和 Two-stage 检测器（如 Faster R-CNN）的主要区别？**

```
答：
1. 流程差异：YOLO是one-stage，单次前向传播完成检测和分类；
   Faster R-CNN是two-stage，先生成候选框再分类回归
2. 速度差异：YOLO更快（45 FPS vs 7 FPS），适合实时应用
3. 精度差异：YOLO定位精度较低，但 recall 和背景误检控制好
4. 原理差异：YOLO将检测视为回归问题，Faster R-CNN是分类+回归
```

**Q2: YOLOv1 的输出为什么是 7×7×30？**

```
答：
- 7×7：将图像划分为49个grid cells，每个cell负责预测中心落在其中的目标
- 30 = 5×2 + 20：每个cell预测2个bounding box（每个5维：x,y,w,h,confidence）
  加上20个类别概率（PASCAL VOC有20类）
- 总预测数：49 × 2 = 98 个 bounding boxes
```

**Q3: YOLOv1 的损失函数为什么这样设计？**

```
答：
1. 坐标损失：使用(x,y,w,h)，其中w,h开根号处理大小框差异
2. 置信度损失：分有物体和无物体两种情况，无物体权重λ_noobj=0.5解决正负样本不平衡
3. 分类损失：条件概率Pr(Class|Object)，只在有物体时计算
4. 权重设置：λ_coord=5强调定位重要性
```

**Q4: YOLOv1 如何解决小目标检测问题？有什么局限？**

```
答：
- 解决方式：使用全卷积网络保持空间信息，网格预测机制
- 局限：
  1. 每个cell只能预测2个框且同类别，密集小目标容易漏检
  2. 只有单层7×7预测，缺乏多尺度特征
  3. 后续版本YOLOv2/v3通过Anchor Boxes和多尺度预测改进
```

**Q5: YOLOv1 为什么速度快？**

```
答：
1. 单次前向传播，无需候选框生成阶段
2. 全卷积网络结构，GPU并行计算友好
3. 将检测转化为回归，端到端优化
4. 网络结构相对简单（24层卷积+2层FC）
```

### 5.2 深度追问

**Q6: 为什么坐标损失中宽高开根号？**

> 假设两个框都偏差了2个像素：
> - 大框 100×100：偏差比例 2/100 = 2%
> - 小框 10×10：偏差比例 2/10 = 20%
> 
> 直接计算 MSE 两者惩罚相同，但小框的相对误差更大。
> 开根号后：√100=10, √10≈3.16，同样2像素偏差，小框的损失权重更大。

**Q7: YOLOv1 训练时如何处理正负样本？**

> - 正样本：负责检测真实目标的 grid cell（中心点落在该cell）
> - 负样本：不含目标的 grid cells（占大多数）
> - 每个正样本cell的两个框中，IOU大的负责回归该目标
> - 通过 λ_noobj=0.5 降低负样本损失的权重，解决类别不平衡

**Q8: YOLOv1 的 confidence 和 class probability 有什么区别？**

> - confidence = Pr(Object) × IOU(pred, truth)
>   表示"该框包含目标且定位准确的置信度"
> - class probability = Pr(Class_i | Object)
>   表示"在包含目标的前提下，属于某类的概率"
> - 最终得分 = confidence × class_probability

### 5.3 手撕代码要点

```python
# YOLOv1 损失函数核心逻辑（面试常考）
def yolo_loss(pred, target, S=7, B=2, C=20):
    """
    pred: (batch, S, S, B*5+C) = (N, 7, 7, 30)
    target: (batch, S, S, 6)  # [x, y, w, h, conf, class]
    """
    # 提取预测值
    pred_box1 = pred[..., 0:5]   # 第一个框 [x, y, w, h, conf]
    pred_box2 = pred[..., 5:10]  # 第二个框
    pred_cls = pred[..., 10:30]  # 类别概率
    
    # 1. 坐标损失 (只计算负责检测的框)
    coord_loss = λ_coord * (
        (pred_x - target_x)**2 + 
        (pred_y - target_y)**2 +
        (torch.sqrt(pred_w) - torch.sqrt(target_w))**2 +
        (torch.sqrt(pred_h) - torch.sqrt(target_h))**2
    )
    
    # 2. 置信度损失
    obj_loss = (pred_conf - target_conf)**2
    noobj_loss = λ_noobj * (pred_conf - 0)**2  # 无目标时conf=0
    
    # 3. 分类损失
    cls_loss = (pred_cls - target_cls)**2
    
    return coord_loss + obj_loss + noobj_loss + cls_loss
```
