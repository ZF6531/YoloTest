## 1. 三维重建概述

### 定义
**三维重建**是指通过传感器（相机、激光雷达、深度相机等）采集的二维或多维观测数据，恢复场景或物体的三维几何结构与外观的过程。

### 技术路线演进

```
早期几何方法（1980s-2000s）
    │
    ├── 立体视觉（Stereo Vision）
    ├── 运动恢复结构（SfM）
    └── 多视图立体（MVS）
            │
            ▼
传感器融合时代（2000s-2010s）
    │
    ├── RGB-D 相机（Kinect、RealSense）
    ├── 激光雷达（LiDAR）
    └── 视觉 SLAM / 稠密重建
            │
            ▼
深度学习时代（2015s-至今）
    │
    ├── 单目深度估计（Monocular Depth Estimation）
    ├── 基于体素/点云的 3D CNN
    ├── 神经辐射场（NeRF, 2020）
    └── 3D Gaussian Splatting（2023）
```

## 2. 基础数学与几何概念

### 2.1 坐标系

三维重建涉及多个坐标系的转换：

| 坐标系 | 符号 | 说明 |
|--------|------|------|
| **世界坐标系** | $(X_w, Y_w, Z_w)$ | 全局参考坐标系，描述物体在真实空间中的位置 |
| **相机坐标系** | $(X_c, Y_c, Z_c)$ | 以相机光心为原点，Z 轴指向相机前方 |
| **图像坐标系** | $(x, y)$ | 以成像平面中心为原点，单位通常为毫米 |
| **像素坐标系** | $(u, v)$ | 以图像左上角为原点，单位为像素 |

### 2.2 齐次坐标（Homogeneous Coordinates）
将 n 维欧氏空间中的点表示为 n+1 维向量，使投影变换可以用矩阵乘法表示。

- 3D 点：$\mathbf{X} = [X, Y, Z, 1]^T$
- 2D 点：$\mathbf{x} = [x, y, 1]^T$

### 2.3 刚体变换（Rigid Transformation）
只包含旋转和平移，保持物体形状和大小不变：

$$
\mathbf{X}_c = R \mathbf{X}_w + t
$$

其中 $R \in SO(3)$ 是 $3 \times 3$ 旋转矩阵，$t \in \mathbb{R}^3$ 是平移向量。

合并为 $4 \times 4$ 的**变换矩阵**（Transformation Matrix）：

$$
T = \begin{bmatrix} R & t \\ 0^T & 1 \end{bmatrix}
$$

### 2.4 对极几何（Epipolar Geometry）
描述两张图像之间的内在几何关系。

- **极点（Epipole）**：一张相机光心在另一张图像上的投影点
- **极线（Epipolar Line）**：空间中一点在两幅图像上投影点之间的约束线
- **基本矩阵（Fundamental Matrix）** $F$：$3 \times 3$ 矩阵，满足 $\mathbf{x}'^T F \mathbf{x} = 0$，描述未标定相机间的对极约束
- **本质矩阵（Essential Matrix）** $E$：$E = K'^T F K$，描述已标定相机间的对极约束，$E = [t]_\times R$

### 2.5 三角测量（Triangulation）
已知两幅图像的相机位姿和对应像素点，通过射线相交恢复空间点的三维坐标。

由于噪声存在，两条射线通常不相交，采用**最小二乘法**或**中点法**求解最优三维点。

## 3. 相机模型与成像原理

### 3.1 针孔相机模型（Pinhole Camera Model）
最基础的理想成像模型：

$$
Z_c \begin{bmatrix} u \\ v \\ 1 \end{bmatrix} = K [R | t] \begin{bmatrix} X_w \\ Y_w \\ Z_w \\ 1 \end{bmatrix}
$$

其中 **内参矩阵（Intrinsic Matrix）** $K$ 为：

$$
K = \begin{bmatrix} f_x & 0 & c_x \\ 0 & f_y & c_y \\ 0 & 0 & 1 \end{bmatrix}
$$

- $f_x, f_y$：焦距（以像素为单位）
- $c_x, c_y$：主点（图像中心）
- $[R | t]$：外参（相机位姿）

### 3.2 镜头畸变（Lens Distortion）
真实镜头会引入畸变，主要包括：

| 畸变类型 | 说明 |
|----------|------|
| **径向畸变（Radial Distortion）** | 由镜头曲率引起，离中心越远畸变越大。常用多项式模型：$x_{distorted} = x(1 + k_1r^2 + k_2r^4 + k_3r^6)$ |
| **切向畸变（Tangential Distortion）** | 由镜头与成像平面不平行引起。模型：$x_{distorted} = x + [2p_1xy + p_2(r^2 + 2x^2)]$ |

### 3.3 相机标定（Camera Calibration）
通过拍摄已知图案（如棋盘格）来确定相机的内参和畸变系数。

- **经典方法**：张正友标定法（Zhang's Method），利用多张不同姿态的棋盘格图像求解内参和外参
- **目的**：消除畸变、获得准确的焦距和主点、为后续位姿估计和三维重建提供基础

## 4. 传统三维重建方法

### 4.1 立体视觉（Stereo Vision）
使用两台标定好的相机（双目相机）同时拍摄同一场景，通过匹配左右图像的对应点，利用视差（Disparity）计算深度。

**视差与深度关系**：
$$
Z = \frac{f \cdot B}{d}
$$

- $f$：焦距
- $B$：基线距离（两相机光心间距）
- $d$：视差（同一空间点在左右图像上的像素位移）

**特点**：
- 计算简单、实时性好
- 对纹理less区域（白墙、天空）匹配困难
- 基线长度决定了深度测量范围和精度

### 4.2 运动恢复结构（Structure from Motion, SfM）
从一系列无序或有序的二维图像中，同时恢复相机位姿和稀疏三维点云。

**典型流程**：
```
特征提取（SIFT/SURF/ORB）
    ↓
特征匹配 + RANSAC 外点剔除
    ↓
初始两视图重建（三角测量）
    ↓
增量式添加新图像（PnP 求解位姿）
    ↓
光束法平差（Bundle Adjustment, BA）
    ↓
输出：相机位姿 + 稀疏点云
```

**光束法平差（BA）**：
联合优化所有相机参数和三维点坐标，最小化重投影误差：

$$
\min_{R_i, t_i, X_j} \sum_{i,j} \| \pi(R_i, t_i, X_j) - x_{ij} \|^2
$$

- **全局 SfM**：先恢复所有图像的相对位姿，再统一进行 BA，对大场景更鲁棒（如 OpenMVG）
- **增量式 SfM**：逐张添加图像并局部优化，适合中小规模场景（如 COLMAP）

### 4.3 多视图立体（Multi-View Stereo, MVS）
在已知相机位姿的基础上，从多张图像恢复**稠密三维表面**。

**常用方法**：

| 方法 | 原理 |
|------|------|
| **体素法（Volumetric MVS）** | 将空间离散化为体素网格，通过光一致性（Photo-consistency）判断体素是否属于表面 |
| **PatchMatch 立体** | 在图像平面上传播和随机扰动局部平面假设，寻找最佳深度和法向 |
| **深度图融合** | 每张图像估计一张深度图，通过一致性检查和融合生成点云或 mesh |

**代表系统**：COLMAP（SfM + MVS 集成）、OpenMVS、MVE

### 4.4 视觉 SLAM（Simultaneous Localization and Mapping）
在相机运动过程中，**实时**估计自身位姿并构建环境地图。

| 类型 | 代表系统 | 特点 |
|------|----------|------|
| **稀疏 SLAM** | ORB-SLAM2/3 | 实时恢复相机轨迹和稀疏特征点地图 |
| **半稠密 SLAM** | LSD-SLAM, DSO | 恢复梯度明显的像素深度，半稠密地图 |
| **稠密 SLAM** | ElasticFusion, BAD-SLAM | 恢复稠密表面，通常需要 GPU 加速 |
| **语义 SLAM** | Kimera, Vox-Fusion | 同时估计几何和语义信息 |

**核心模块**：
- **前端（Tracking）**：特征提取与匹配，估计帧间位姿
- **后端（Optimization）**：图优化或 BA，消除累积漂移
- **回环检测（Loop Closure）**：识别 revisit 场景，校正全局轨迹
- **建图（Mapping）**：生成并更新三维地图

## 5. 深度学习三维重建

### 5.1 单目深度估计（Monocular Depth Estimation）
从单张 RGB 图像预测每个像素的深度值。

**经典网络**：
- **MiDaS**：多数据集混合训练，预测相对深度
- **DPT（Dense Prediction Transformer）**：基于 ViT 架构，泛化能力强
- **Depth Anything**：利用大规模无标签数据训练，零样本深度估计

**挑战**：
- 尺度模糊性（Scale Ambiguity）：单目无法确定绝对尺度
- 边缘模糊：物体边界处深度预测不准确

### 5.2 基于体素的 3D CNN

将三维空间离散化为体素网格，使用 3D 卷积网络直接从图像或点云中学习三维形状。

- **Occupancy Networks**：预测每个体素是否被占据
- **VoxelNet**：用于点云目标检测和三维重建
- **缺陷**：内存消耗大，分辨率受限（通常 $128^3$ 或 $256^3$）

### 5.3 点云生成网络

**PointNet / PointNet++**：直接处理无序点云，学习点级和全局特征。

**Point Cloud Transformer / Point-E**：从图像或文本生成三维点云。

### 5.4 网格（Mesh）生成

**Marching Cubes**：从体素场中提取等值面，生成三角网格。

**深度学习网格方法**：
- **Pixel2Mesh**：从单张图像迭代变形椭球体生成 mesh
- **Occupancy Networks / DeepSDF**：学习隐式场，通过 ray marching 或 marching cubes 提取表面

### 5.5 神经辐射场（NeRF, Neural Radiance Field）

**NeRF（2020）** 开启了隐式神经表示的新范式。

**核心思想**：
用一个全连接神经网络（MLP）建模场景的**体积密度** $\sigma$ 和**颜色** $c$：

$$(\sigma, c) = \text{MLP}(\mathbf{x}, \mathbf{d})$$

- $\mathbf{x} = (x, y, z)$：空间三维坐标
- $\mathbf{d} = (\theta, \phi)$：观察方向

**渲染过程**：
沿每条相机射线采样点，通过**体渲染（Volume Rendering）**积分得到像素颜色：

$$
\hat{C}(r) = \int_{t_n}^{t_f} T(t) \sigma(r(t)) c(r(t), d) dt
$$

其中 $T(t) = \exp(-\int_{t_n}^{t} \sigma(s) ds)$ 是透射率。

**训练方式**：
最小化渲染图像与真实图像的 photometric loss：

$$
\mathcal{L} = \sum_r \| \hat{C}(r) - C(r) \|^2
$$

**NeRF 的改进方向**：

| 方法 | 解决的问题 |
|------|-----------|
| **Instant-NGP** | 引入哈希编码，训练速度从小时级降至秒级 |
| **Mip-NeRF 360** | 解决抗锯齿和无界场景问题 |
| **NeRF-W** | 处理光照变化和动态场景（如户外地标） |
| **D-NeRF** | 建模动态变形场，重建时变场景 |

### 5.6 3D Gaussian Splatting（3DGS）

**3D Gaussian Splatting（2023）** 是目前最热门的实时神经渲染方法。

**核心思想**：
用数百万个**三维高斯椭球**表示场景，每个高斯具有位置、协方差（决定形状和朝向）、颜色（球谐系数）和不透明度。

**渲染方式**：
将三维高斯投影到屏幕空间，按深度排序后通过**光栅化**快速 alpha 混合，无需神经网络前向传播：

$$
C = \sum_{i=1}^{N} c_i \alpha_i \prod_{j=1}^{i-1}(1 - \alpha_j)
$$

**相比 NeRF 的优势**：
- **训练速度快**：数分钟级
- **渲染速度极快**：1080p 可达 100+ FPS，适合 VR/AR 实时应用
- **编辑性好**：可直接对高斯进行添加、删除、移动、变形操作

**挑战**：
- 存储开销较大（完整场景通常 200MB~1GB）
- 动态场景和泛化生成仍在研究中

## 6. 三维场景表示方法

三维重建的输出需要选择合适的数据结构表示场景几何和外观：

| 表示方法 | 优点 | 缺点 | 典型应用 |
|----------|------|------|----------|
| **点云（Point Cloud）** | 获取简单、存储高效、保留原始采样信息 | 无拓扑结构、渲染有孔洞、噪声敏感 | LiDAR 扫描、SfM 输出、显示和测量 |
| **体素（Voxel）** | 规则网格、适合 CNN 处理、布尔运算简单 | 分辨率受限、内存 $O(N^3)$ | 医学影像、游戏体积云、早期 3D CNN |
| **网格（Mesh）** | 紧凑、支持硬件光栅化、有显式拓扑 | 生成困难、对复杂拓扑不灵活 | 游戏资产、CAD、3D 打印 |
| **隐式场（Implicit Field）** | 连续可微、分辨率无限、适合神经网络 | 渲染需要采样查询、不能直接编辑 | NeRF、Occupancy Networks、DeepSDF |
| **高斯泼溅（3D Gaussian）** | 渲染极快、训练快速、可编辑 | 存储较大、动态场景支持有限 | 实时渲染、数字孪生、VR 漫游 |

### 6.1 点云处理技术

- **下采样（Downsampling）**：减少点数量，常用体素网格滤波（Voxel Grid Filter）
- **法线估计（Normal Estimation）**：通过局部邻域 PCA 计算点云法向
- **配准（Registration）**：
  - **ICP（Iterative Closest Point）**：迭代最小化对应点距离
  - **NDT（Normal Distributions Transform）**：基于概率分布的配准，对初始位姿要求低
- **表面重建**：Poisson Reconstruction、Ball-Pivoting Algorithm、Alpha Shapes

### 6.2 隐式场表示

- **Occupancy Network**：$f(x) \in [0, 1]$，判断空间点是否在物体内
- **DeepSDF**：$f(x) \in \mathbb{R}$，表示点到最近表面的有符号距离
- **NeRF**：$(\sigma, c)$，同时编码几何和外观

## 7. 评估指标

### 7.1 几何精度

| 指标 | 说明 |
|------|------|
| **Chamfer Distance (CD)** | 预测点云与真值点云之间的双向最近点距离平均，衡量点云相似度 |
| **F-Score** | 在特定阈值下，重建表面与真值表面的精度和召回率的调和平均 |
| **Hausdorff Distance** | 两组点之间的最大最小距离，对离群点敏感 |
| **Mean Absolute Error (MAE)** | 深度图或点云坐标的平均绝对误差 |
| **RMSE** | 均方根误差，惩罚大误差 |

### 7.2 渲染质量

| 指标 | 说明 |
|------|------|
| **PSNR** | 峰值信噪比，衡量图像像素级差异 |
| **SSIM** | 结构相似性，更符合人眼感知 |
| **LPIPS** | 基于深度特征学习的感知相似度，衡量图像感知差异 |

### 7.3 位姿估计精度

| 指标 | 说明 |
|------|------|
| **ATE（Absolute Trajectory Error）** | 估计轨迹与真值轨迹之间的绝对偏差，通常用 RMSE 衡量 |
| **RPE（Relative Pose Error）** | 相邻帧之间的相对位姿误差，衡量局部一致性 |

## 8. 应用领域

| 领域 | 应用场景 |
|------|----------|
| **自动驾驶** | 高精地图构建、环境感知、BEV（Bird's Eye View）重建 |
| **机器人** | SLAM 导航、机械臂抓取、场景理解 |
| **文化遗产** | 古建筑数字化、文物三维存档、虚拟博物馆 |
| **游戏与影视** | 实景扫描资产、虚拟制片（Virtual Production）、数字人 |
| **建筑与测绘** | BIM 建模、地形测量、施工进度监控 |
| **医疗** | CT/MRI 三维可视化、手术导航、假体设计 |
| **AR/VR** | 空间锚定、虚实融合、沉浸式漫游 |
| **电商** | 商品三维展示、虚拟试衣、家具摆放 |
